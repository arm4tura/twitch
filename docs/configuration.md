# Настройки распознавания и словарь мата

## Словарь мата (`banwords.txt`)

Программа ищет мат по вашему словарю - это обычный текстовый файл, по одному слову в строке. За основу можно взять `backend/banwords.example.txt` и добавить свои слова.

Слова сверяются не буквально: программа приводит их к базовой форме, поэтому одно слово в словаре ловит все его формы - падежи, приставки, окончания. Оговорки и ошибки распознавания подхватывает нечёткий поиск.

## Расширенный режим

В окне нового проекта переключитесь на **«Расширенный»** - откроются дополнительные настройки:

- **Движок распознавания** - по умолчанию GigaAM v3.
- **Диапазон** (`range_in` / `range_out`) - обработать только кусок записи, а не весь стрим.
- **Тестовый транскрипт** - подсунуть готовый транскрипт, чтобы отладить экспорт без запуска распознавания.

## Смена движка распознавания

По умолчанию стоит **GigaAM v3**: он точнее на русском мате и работает через onnxruntime - без torch и CUDA. На Windows его ускоряет любая видеокарта (DirectML), без видеокарты он идёт на процессоре. При желании можно переключиться на другой.

### WhisperX

```
--transcriber whisperx
```

faster-whisper через PyTorch + CUDA, модель `large-v3` с точной привязкой к словам. Защита от галлюцинаций включена по умолчанию.

WhisperX не входит в установщик (это несколько гигабайт torch и CUDA). Он доступен только при запуске из исходников: `pip install -e ".[whisperx]"` и `twitch-cut prefetch --whisperx`.

### whisper.cpp

Пригодится, если PyTorch + CUDA на Windows не запускается. Своя CUDA-сборка, встроенное определение речи, отдельный кэш:

```powershell
twitch-cut process ... `
  --transcriber whispercpp `
  --whisper-cpp-bin   "C:\tools\whisper.cpp\whisper-cli.exe" `
  --whisper-cpp-model "C:\tools\whisper.cpp\models\ggml-large-v3.bin"
```

## Чувствительность к мату

В **Настройках** есть одна ручка на всё, что определяет ширину заглушки - **«Чувствительность к мату»**. Она отвечает на единственный вопрос: что для вас дороже - услышанный в записи мат или лишние доли секунды заглушённой чистой речи.

| уровень | что делает |
| --- | --- |
| Осторожно | узкие заглушки, чистая речь почти не страдает; хвост мата может остаться слышимым |
| Обычно | значение по умолчанию, точка равновесия |
| Строго | заглушки шире, больше кандидатов «на проверку»; мат почти не проскакивает |

Замер на 15 минутах реального стрима (эталон - правки монтажёра): «Строго» заглушает целиком 36 матов из 142 против 30 у «Обычно» и 9 у «Осторожно», платя за это 20.9 секунды заглушки вне матов против 17.5 и 15.6. Точность при этом выше «Обычно» не растёт - уровень меняет не количество найденного мата, а то, насколько плотно заглушка сидит вокруг слова.

Из командной строки то же самое - `--sensitivity low|balanced|high`. Отдельные параметры (`--mute-padding-after-ms` и т.п.) уровень перебивают, если нужно подвинуть что-то одно.

## Параметры заглушек

Эти параметры от уровня чувствительности не зависят:

- `mute_max_seconds` - максимальная длина одной заглушки.
- `mute_max_word_seconds` - предохранитель от битых таймингов распознавания: сколько максимум может длиться одно слово.
