# Настройки распознавания и словарь мата

## Словарь мата (`banwords.txt`)

Программа ищет мат по вашему словарю - это обычный текстовый файл, по одному слову в строке. За основу можно взять `backend/banwords.example.txt` и добавить свои слова.

Слова сверяются не буквально: программа приводит их к базовой форме, поэтому одно слово в словаре ловит все его формы - падежи, приставки, окончания. Оговорки и ошибки распознавания подхватывает нечёткий поиск.

## Расширенный режим

В окне нового проекта переключитесь на **«Расширенный»** - откроются дополнительные настройки:

- **Движок распознавания** - по умолчанию GigaAM v3.
- **Диапазон** (`range_in` / `range_out`) - обработать только кусок записи, а не весь стрим.
- **Тестовый транскрипт** - подсунуть готовый транскрипт, чтобы отладить экспорт без запуска распознавания.

## Смена движка распознавания

По умолчанию стоит **GigaAM v3**: он точнее на русском мате и не тянет тяжёлый CUDA-стек. При желании можно переключиться на другой.

### WhisperX

```
--transcriber whisperx
```

faster-whisper через PyTorch + CUDA, модель `large-v3` с точной привязкой к словам. Защита от галлюцинаций включена по умолчанию.

### whisper.cpp

Пригодится, если PyTorch + CUDA на Windows не запускается. Своя CUDA-сборка, встроенное определение речи, отдельный кэш:

```powershell
twitch-cut process ... `
  --transcriber whispercpp `
  --whisper-cpp-bin   "C:\tools\whisper.cpp\whisper-cli.exe" `
  --whisper-cpp-model "C:\tools\whisper.cpp\models\ggml-large-v3.bin"
```

## Параметры заглушек

- `mute_max_seconds` - максимальная длина одной заглушки.
- `mute_join_gap_ms` - если между двумя матами промежуток меньше этого значения, они объединяются в одну заглушку.
- запас по краям (±80/120 мс) - небольшой отступ вокруг слова, чтобы не обрезать его на границе.
