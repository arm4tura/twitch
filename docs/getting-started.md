# Установка и первый запуск

## Что нужно

- Windows 10/11 или macOS 12+
- ~10 ГБ свободного места на диске
- Видеокарта NVIDIA - не обязательна. С ней распознавание идёт заметно быстрее, без неё работает на процессоре, просто медленнее. Ускорение доступно только на Windows; на macOS распознавание всегда идёт на CPU.

## Установка

### Windows

1. Откройте страницу [**Releases**](https://github.com/arm4tura/twitch/releases) и скачайте последний `Twitch Cut Setup.exe`.
2. Запустите установщик и пройдите мастер (можно выбрать папку).
3. Откройте **Twitch Cut** из меню «Пуск».

### macOS

1. На странице [**Releases**](https://github.com/arm4tura/twitch/releases) скачайте `.dmg` под свой процессор: `arm64` - для Apple Silicon (M1/M2/M3…), `x64` - для Intel-маков.
2. Откройте образ и перетащите **Twitch Cut** в «Программы».
3. Первый запуск: правый клик по иконке → **«Открыть»** → **«Открыть»** ещё раз. Это нужно один раз, потому что сборка пока не подписана Apple-сертификатом (иначе macOS блокирует «приложение от неустановленного разработчика»).

## Первый запуск

При первом запуске программа сама скачает всё необходимое, покажется окно с прогрессом. Она:

- скачает свой Python (системный ставить не нужно);
- поставит нужные библиотеки - с ускорением на видеокарте, если найдёт NVIDIA (Windows), иначе обычные;
- скачает модели для распознавания речи.

Это разовая процедура, ~10-15 минут на быстром интернете. Дальше программа запускается сразу.

Все данные (модели, логи, рабочие файлы) лежат рядом с программой или в служебной папке приложения:

- **Windows:** `%APPDATA%\Twitch Cut`
- **macOS:** `~/Library/Application Support/Twitch Cut` (логи - в `~/Library/Logs/Twitch Cut`)

## Если первый запуск не удался

В окне с прогрессом есть две кнопки:

- **«Показать лог»** - откроет `bootstrap.log`, там подробности ошибки.
- **«Повторить»** - попробует подготовку заново.

Чаще всего помогает просто «Повторить»: скачивание моделей иногда обрывается, и второй заход проходит нормально.
