# Как это работает внутри

Раздел для тех, кому интересна начинка. Чтобы пользоваться программой, это знать не нужно - она всё делает сама.

## Путь от видео до заглушек

```
запись стрима  ->  звук  ->  распознанный текст  ->  найденный мат  ->  проект для Vegas
```

1. **Извлечение звука.** Из записи достаётся аудиодорожка (нужный кусок, если задан диапазон).
2. **Распознавание речи.** Программа переводит речь в текст и запоминает, в какую секунду прозвучало каждое слово. По умолчанию этим занимается [GigaAM v3](https://github.com/salute-developers/GigaAM) - русский движок распознавания от Salute. Длинную запись он сам режет на куски по паузам.
3. **Поиск мата.** Каждое слово приводится к базовой форме, поэтому одно слово в словаре ловит все его формы («хуёвый», «хуёвого», «хуёвым» - это одно и то же). Дальше слова сверяются с вашим словарём `banwords.txt`. Оговорки и ошибки распознавания подхватывает нечёткий поиск.
4. **Сборка заглушек.** Заглушка ставится ровно на слово-мат плюс небольшой запас по краям, чтобы не обрезать его. Соседние маты объединяются в одну заглушку, а чистая речь между ними не глушится.
5. **Экспорт.** Программа сохраняет два файла: список заглушек `decisions.json` и скрипт `vegas_build.cs` для Vegas Pro 21.

## Повторная обработка идёт быстро

Каждый шаг сохраняется в кэш (`work/<job>/cache/`), так что если вы запустите обработку ещё раз, программа не будет считать всё заново. Пересчитать конкретный шаг можно флагами `--force-extract`, `--force-transcribe`, `--force-detect`.

## Что попадает в Vegas Pro 21

После обработки в папке прогона (`work/<название>_<время>/`) появятся два файла:

- **`decisions.json`** - список всех заглушек в читаемом виде. Его можно править руками.
- **`vegas_build.cs`** - скрипт. В Vegas: `Tools -> Scripting -> Run Script...`, выберите этот файл. На таймлайне появятся регионы `MUTE profanity`, а аудио будет разрезано и заглушено ровно на границах слов.

## Другой движок распознавания

По умолчанию стоит GigaAM v3 - он точнее ловит русский мат и даёт узкие тайминги по словам. При желании можно переключиться на WhisperX или whisper.cpp, это описано в [configuration.md](./configuration.md).
